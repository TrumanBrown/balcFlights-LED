# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/TrumanBrown/balcFlights-LED/security/advisories/new). Don't open a public issue for them.

Include what you found, how to reproduce it, and what an attacker could do with it.

## Supported Versions

Only the latest commit on `main` is supported.

## Scope

In scope: the code in this repository, its CI workflow, and the setup steps in the README and `docs/`.

Out of scope: the seattlebalc.com API, the rpi-rgb-led-matrix driver, and luma.led_matrix. Report issues in those to their maintainers.
